# ProHealth — Backend

This is the backend API for the ProHealth Telemedicine Platform.

📖 Full documentation, features, and setup guide:
👉 [View Main README](https://github.com/TahaY291/telemedicine-frontend)

## Environment Variables

Create a `.env` file in the root of the project and add the following:

```env
PORT=
MONGODB_URI=
CORS_ORIGIN=
NODE_ENV=production
CLOUDINARY_CLOUD_NAME=
CLOUDINARY_API_KEY=
CLOUDINARY_API_SECRET=
ACCESS_TOKEN_SECRET=
ACCESS_TOKEN_EXPIRY=
REFRESH_TOKEN_SECRET=
REFRESH_TOKEN_EXPIRY=
SMTP_USER=
SMTP_PASS=
SENDER_EMAIL=
ALLOWED_ORIGINS=
```
## Quick Start
git clone https://github.com/TahaY291/Telemedicine-backend
cd Telemedicine-backend
npm install
npm start
